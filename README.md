## 📖 Overview

AI Codebase Architect is an intelligent developer assistant that analyses source code repositories using Artificial Intelligence. It helps developers understand project architecture, review code quality, identify potential security issues, generate documentation, and interact with repositories through a modern web interface.

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/saiswaroop66/AI-Codebase-Architect.git
```

```bash
cd AI-Codebase-Architect
```

### Create a virtual environment

```bash
python -m venv venv
```

### Activate the environment

#### Windows

```bash
venv\Scripts\activate
```

#### Linux / macOS

```bash
source venv/bin/activate
```

### Install dependencies

```bash
pip install -r requirements.txt
```

## 🔑 Environment Variables
